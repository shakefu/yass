# Context

Reference and AI-authored working material for the Yass language spec. Keep written artifacts here.

## Start here

- `yass-reference.md`: language and document-format reference.
- `GUIDANCE.md`: authoring guidance for structuring and scoping specs.
- `BRAINSTORMING.md`: the dialogue an agent runs to elicit a spec set from a user before one exists; served by the CLI as `yass docs brainstorming`.
- `experiment/`: provisional design research and feedback; nothing here is authoritative.

Maintain this index when files are added, removed, or substantially changed.
