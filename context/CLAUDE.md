# Directory status

The context directory contains reference files related to the Yass language spec.

Also this contains written artifacts that are used by AI.

No written artifacts should be created outside this directory.

## Index

This index section MUST be maintained whenever files are added, removed, or substantially changed.

## Files

- CLAUDE.md: This file.
- yass-reference.md: A high level user guide (AI guide) for writing Yass language specs, which should be used by Agents to understand the Yass language spec more completely when creating specs.
- GUIDANCE.md: A high level user guide (AI guide) for writing Yass language specs, which should be used by AI to understand best practices in structuring and scoping specs.

## Subdirectories

- experiment/: Contains files related to active experiments on the Yass language spec. Nothing in this directory should be considered authortative.
