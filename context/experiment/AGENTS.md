# Experiment corpus

Provisional research on the Yass language spec. Treat all contents as non-authoritative and non-permanent.

## Navigate by purpose

- `FINDINGS.md`: evidence ledger from probe rounds.
- `*-FEEDBACK.md`, `OPEN-FEEDBACK.md`: agent feedback on guidance and format.
- `DESIGN-BLOCKS.md`, `MAN-ALIGNMENT.md`, `NOTES.md`, `RECOMMENDATIONS.md`: design proposals and triage.
- `IDEAS.md`, `FUTURE.md`, `TOOLING.md`, `FIXES.md`: backlog, open questions, and follow-ups.
- `TEST-TAXONOMY.md`: testing model for spec obligations.
- `cold-prompt.md`, `run-prompt.md`: experiment prompts.

Maintain this index when files are added, removed, or substantially changed.
