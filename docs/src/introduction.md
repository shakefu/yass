# yass

**Yet Another Spec Syntax** — a YAML-based specification language for
AI-agent-driven development. Specs capture desired behavior and are consumed to
drive TDD and implementation generation.

> Early work in progress.

This site carries the authoritative language documents — the same corpus the
`yass` CLI serves embedded via `yass docs` — and hosts the
[JSON Schema](schema.md) that editors use to validate `.yass.yaml` files.
